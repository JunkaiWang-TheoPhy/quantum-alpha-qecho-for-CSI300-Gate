# Quantum Alpha Gate design

## Purpose

Create a separate, public GitHub Pages gateway at
`quantum-alpha-qecho-for-CSI300-Gate`. The page presents project identity and
routes judges to the three stable material folders in the main repository.

## Visual system

- A full-viewport distant-mountain photograph forms a pale atmospheric layer.
- The right hero uses an original snow-mountain adaptation of the back-facing
  wanderer composition supplied by the user.
- PPT, Video, and Demo use three distinct original quantum-chip macro images.
- White, mist blue, alpine green, graphite, and a restrained violet accent keep
  the page bright and legible.

## Navigation

- Top right: this Gate's GitHub repository.
- Three primary cards: `ppt/`, `video/`, and `demo/` folders in
  `JunkaiWang-TheoPhy/quantum-alpha-qecho-for-CSI300`.
- No legacy-page or old evidence-report link is exposed.
